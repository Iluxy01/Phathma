# Phathma

Кооперативный по духу (пока одиночный) хоррор про охоту на призраков для браузера телефона. Низкополигональная 3D-графика на Three.js, без сборки и без внешних файлов.

## Запуск

Нужен любой статический сервер (ES-модули не работают через `file://`):

```
python3 -m http.server 8000
# открыть http://localhost:8000 (или IP компьютера с телефона в той же сети)
```

Можно включить GitHub Pages для этой ветки — игра заработает по ссылке.

## Игра вдвоём

В главном меню — «👥 Играть вдвоём». Один игрок нажимает «Создать игру» и называет код, второй вводит его (или нажимает игру в списке) — хост жмёт «Начать вдвоём».

- **На claude.ai** связь идёт через встроенный канал страницы (capability `room`). Напарнику нужен доступ к странице — кнопка «Поделиться».
- **В HTML-файле** (`dist/phathma.html`) по умолчанию «Через сервер»: обмен идёт через три публичных бесплатных MQTT-брокера сразу (EMQX, HiveMQ, Mosquitto) по защищённому WebSocket — работает в любой сети; повторы отсекаются по номерам. Есть и способ «Напрямую P2P» (WebRTC через бесплатный сервер PeerJS). У обоих игроков должен быть выбран один способ.

Как это устроено: хост полностью симулирует мир и 20 раз в секунду рассылает снимок (призрак, двери, свет, предметы, ЭМП, температуры); у напарника призрак и игрок сглажены интерполяцией (~120 мс), его действия идут хосту запросами, а двери/свет/техника срабатывают у нажавшего сразу (предсказание). Дом, призрак, проклятый предмет и задания строятся из общего «зерна» случайности — у обоих всё одинаково. Призрак охотится на того, кого заметит; погибший становится невидимым наблюдателем.

## Как играть

Возьмите снаряжение со стеллажа в фургоне, найдите комнату призрака, соберите 3 улики, отметьте их в журнале, выберите тип призрака и нажмите красную кнопку в фургоне.

- **Улики (9):** ЭМП 5, ответ радиоприёмника, минусовая температура, УФ-отпечатки, записи в блокноте, призрачные огни (видны через видеокамеру), лазерная сетка, синее пламя свечи, голос на диктофоне.
- **Снаряжение (16 предметов):** ЭМП-детектор, радиоприёмник, термометр, УФ-фонарь, блокнот, видеокамера (+ монитор в фургоне), фотоаппарат, распятие, благовония, соль, успокоительное, датчик движения, направленный микрофон, лазерный проектор, свеча, диктофон. Плюс фонарик всегда с собой.
- **Рассудок** падает в темноте. При низком рассудке призрак начинает **охоту**: входная дверь запирается, свет и электроника мигают. Прячьтесь в шкаф и выключайте электронику.
- **Проклятые предметы:** в каждом доме один из пяти — говорящая доска, музыкальная шкатулка, карты Таро, старое зеркальце, тряпичная кукла. Дают сведения о призраке ценой рассудка и могут вызвать проклятую охоту.
- **Призраки (16):** Скрытень, Барабашка, Бес, Морок, Кикимора, Навка, Упырь, Домовой, Леший, Полуденница, Мара, Анчутка, Вий, Банник, Кощей, Лихо
- **Сложность (5):** Любитель, Опытный, Профессионал, Кошмар (2 улики), Безумие (1 улика). Деньги и уровень сохраняются между играми. — у каждого свой набор улик и особенности поведения (описаны в журнале).

Если поворот экрана на телефоне заблокирован, игра сама разворачивается горизонтально (настройка «Ориентация»). Кнопки можно переставить, увеличить, сделать прозрачнее и отзеркалить: «Раскладка кнопок» в меню или на паузе.

Управление на телефоне: левая половина экрана — джойстик, правая — обзор, кнопки справа.
На ПК: WASD, Shift, E/R/G/F/T, 1–3, J; двойной клик — захват мыши.

Для отладки: `?ghost=bes` (id из `js/ghost.js`) задаёт тип призрака, `?cursed=mirror` (board, musicbox, cards, mirror, doll) — проклятый предмет.

## Структура

- `js/world.js` — дом, двери, свет, мебель, фургон, коллизии, поиск пути
- `js/ghost.js` — типы призраков и ИИ (блуждание, взаимодействия, явления, охота)
- `js/items.js` — снаряжение
- `js/ui.js` — журнал, фургон, результаты, HUD
- `js/audio.js` — процедурный звук (WebAudio)
- `js/main.js` — рендер, управление, игровой цикл
- `js/net.js` — сетевой транспорт (claude.ai room / PeerJS)
- `js/mp.js` — игра вдвоём: лобби, синхронизация мира, аватар напарника
- `js/appliances.js` — телевизор и краны
- `js/cursed.js` — проклятые предметы
- `js/screen.js` — принудительная горизонтальная ориентация и редактор раскладки

## Один файл без сервера

`dist/phathma.html` — вся игра (вместе с Three.js) в одном файле. Его можно просто открыть в браузере двойным щелчком, интернет и сервер не нужны.

Пересборка после изменений кода:

```
npx esbuild@0.20.2 js/main.js --bundle --format=iife --minify --alias:three=./lib/three.module.min.js --outfile=/tmp/game.js
python3 tools/build_single.py /tmp/game.js
```
